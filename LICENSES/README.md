# Preserved license texts

This directory preserves license texts and related notices for upstream
projects and external dependencies referenced by ShaguTweaks-ClassicAPI.

Files stored here are documentary copies. Their presence does not automatically
apply every listed license to the ShaguTweaks-ClassicAPI repository as a whole.

- `ShaguTweaks-MIT.txt` — original ShaguTweaks MIT license preserved from the
  fork's root `LICENSE`.
- `ShaguTweaks-mods-MIT.txt` — MIT license for the adapted
  TokensWorth/ShaguTweaks-mods material documented in
  `THIRD_PARTY_NOTICES.md`.
- `ClassicAPI-GPL-3.0.txt` — verbatim license document from the external
  ClassicAPI repository. ClassicAPI is not bundled here.
- `SuperWoW-LICENSE.txt` — verbatim upstream license from the external
  SuperWoW repository. SuperWoW is not bundled here.

See `../THIRD_PARTY_NOTICES.md` for scope and provenance details.
