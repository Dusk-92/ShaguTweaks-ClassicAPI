# ShaguTweaks-ClassicAPI asset provenance manifest

Audit date: 2026-08-31

This manifest records the currently known provenance of binary artwork and
screenshots shipped by ShaguTweaks-ClassicAPI. No artwork or screenshot was
modified, converted, replaced, or removed during this documentation pass.

A project-level software license does not by itself establish that an upstream
project owned or could independently relicense every third-party or game-derived
visual it distributed. This manifest therefore records what can be verified
without making broader ownership claims.

## Status meanings

- **exact-upstream-git-blob-match** — the file has the same Git blob SHA-1 as
  the corresponding file in the canonical ShaguTweaks upstream repository.
- **unresolved** — origin has not been established well enough to make a more
  specific claim.

Git blob SHA-1 values below are repository object identifiers used to establish
byte-identical upstream matches. They are provenance identifiers, not security
hashes.

## Important licensing boundary

The exact upstream match establishes that these files were inherited from the
ShaguTweaks source tree rather than newly introduced by this fork.

It does **not**, by itself, establish whether every visual element was wholly
created by the upstream project, derived from game assets, or otherwise subject
to separate third-party rights. The files are therefore preserved with
provenance attribution and without any additional relicensing claim beyond
rights actually held by the applicable rights holders.

## Maintenance

When artwork or screenshots are added, removed, or replaced:

1. Record the source or creation history.
2. Record an exact upstream match when one can be verified.
3. Do not guess unresolved provenance.
4. Keep historical attribution when an asset is replaced.
