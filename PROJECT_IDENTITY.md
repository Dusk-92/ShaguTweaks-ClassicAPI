# ShaguTweaks-ClassicAPI project identity

## Canonical project

The canonical ShaguTweaks-ClassicAPI repository designated by the project
maintainer is:

- https://github.com/Dusk-92/ShaguTweaks-ClassicAPI

Copies, mirrors, package caches, downstream forks, and modified versions hosted
elsewhere are independent unless the canonical project explicitly says
otherwise. Hosting or mirroring a fork on GitHub, GitLab, Gitea, Codeberg, an
addon service, or another platform does not by itself create an affiliation,
endorsement, partnership, or ownership relationship with the canonical project.

ShaguTweaks-ClassicAPI targets or references software and game environments
including World of Warcraft, Turtle WoW-like clients/servers, ClassicAPI,
SuperWoW, ShaguTweaks, pfUI, zUI, and other compatibility references documented
in the repository.

Compatibility, testing, source comparison, API integration, or reference use
does not imply endorsement by or affiliation with those projects, their
maintainers, Blizzard Entertainment, or other rights holders.

World of Warcraft and Blizzard Entertainment names, marks, and game assets
remain the property of their respective rights holders. Other project names and
trademarks remain the property of their respective owners.

## Upstream relationship

ShaguTweaks-ClassicAPI is an independent fork of ShaguTweaks and retains the
original upstream attribution and MIT license notice.

The fork is maintained independently. Nothing in this repository should be read
as a statement that the original ShaguTweaks maintainer endorses, supports, or
is responsible for this fork or its releases.

## External dependencies

ClassicAPI is a required external runtime dependency. SuperWoW is optional.
Neither project is bundled into ShaguTweaks-ClassicAPI merely because the addon
integrates with its APIs or runtime behavior.

See `THIRD_PARTY_NOTICES.md` and `LICENSES/` for dependency and license
records.

## Support boundary

The ShaguTweaks-ClassicAPI maintainer is responsible only for code and releases
published by the canonical project. Downstream forks may alter functionality,
packaging, licensing notices, or compatibility behavior and should be treated as
separate projects.
